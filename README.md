# 作品集網站（portfolio）

由 [portfolio-project](https://github.com/44313-architects/portfolio-project) 的產生器匯出的作品集，透過 GitHub Pages 發佈。

- 首頁（列出所有案子）：https://44313-architects.github.io/portfolio/
- 每個案子一個資料夾，例如 https://44313-architects.github.io/portfolio/nantou-1230/

## 新增或更新案子

1. 在產生器按「匯出作品集（HTML）」。
2. 把匯出的檔案改名為 `index.html`，放進該案子的資料夾（新案子就新開一個資料夾，名稱用英文或數字，例如 `taichung-01`）。
3. 新案子要在根目錄 `index.html` 的 `PROJECTS` 陣列加一行（資料夾名稱、案名、一句說明）。
4. commit 並 push，約一分鐘後網站更新。
